# 🌐 Web 3.0 Social Network

Bienvenue dans le dépôt officiel du **Web 3.0 Social Network**, le projet phare de la **Web 3.0 Academy**. Cette application est une plateforme de blog dynamique et performante, conçue pour démontrer la maîtrise d'un écosystème React complet.

## 🛠️ Stack Technologique (Full-Power React)

Pour ce module, nous avons intégré les meilleures bibliothèques du marché pour une expérience développeur et utilisateur optimale :

- **Navigation** : `React Router DOM` pour une gestion fluide des routes et des pages.
- **Gestion des Données** : `TanStack React Query` & `Axios` pour des appels API robustes et une mise en cache intelligente.
- **Formulaires** : `React Hook Form` pour une gestion performante et simplifiée de la saisie utilisateur.
- **Backend (Simulation)** : `JSON Server` pour une API REST fonctionnelle durant le développement.
- **Design & UI** : `Tailwind CSS` (avec DaisyUI) et `Lucide React` pour des icônes modernes et épurées.
- **Expérience Utilisateur** : `React Hot Toast` pour des notifications élégantes et réactives.

## ✨ Fonctionnalités Avancées

- **CRUD Complet** : Création, lecture, mise à jour et suppression de posts via une API simulée.
- **Fetching Intelligent** : Gestion des états de chargement (loading) et d'erreur avec React Query.
- **Validation de Formulaire** : Formulaires sécurisés et réactifs avec React Hook Form.
- **Notifications en Temps Réel** : Retours visuels immédiats lors des actions utilisateur (succès, erreur).
- **Interface Hybride** : Design responsive alliant Material UI et DaisyUI.

## 📂 Structure du Projet

````text
src/
├── api/          # Configuration Axios et requêtes React Query
├── components/   # Composants UI (Lucide Icons, MUI, DaisyUI)
├── hooks/        # Hooks personnalisés et gestion des formulaires
├── pages/        # Différentes vues de l'application (Router)
└── App.jsx       # Configuration des routes et des providers
````
